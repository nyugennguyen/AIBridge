Evolution Strategy

From two-host bridge to terminal-native control plane

AIBridge began as a lean TypeScript/Bun daemon enabling secure cross-machine OpenCode execution. We are expanding that durable foundation into a complete multi-agent orchestration plane.

SHIPPED TODAY (v0.2) bun install -g aibridge

The Reliable Bridge

A focused, production-grade bridge for developers who write code on a MacBook and dispatch integration testing, builds, or scripts to a dedicated Linux host.

  • Topology: Development workstation dispatching to remote testing VPS.
  • Runtime: OpenCode agents kept strictly on loopback (127.0.0.1).
  • Network: Tailscale private transport — zero open ports to the public internet.
  • Security: Granular project path allowlists and token-authorized triggers.
ROADMAP TARGET (v1.0) FIRST RELEASE BOUNDARY

The Terminal Control Plane

A complete orchestration kernel with an interactive TUI for multi-agent coordination, graph planning, human approval gates, and network recovery.

  • Unified TUI: Task graphs, agent states, approval queue, and audit log in one terminal.
  • Multi-Runtime: OpenCode, Claude Code, and Codex adapters preserving native ergonomics.
  • Supervised by Default: Explicit human approval for writes, bounded roles, immutable safety.
  • Durable Kernel: SQLite/WAL event log, controller leases, and instant reconnect recovery.
Core Capabilities

Built for engineers who demand total operational control

Autonomous agents shouldn't run in an opaque cloud box. AIBridge enforces bounded authority, explicit human signoffs, and full post-incident auditability.

Compose Work with Precision

Declare dependency-aware task graphs that dispatch specific jobs to specific machines. Pin memory-heavy testing to high-core VPS instances and lightweight reviews to your laptop.

# Specifying node & runtime affinity
node: "worker-vps.mesh"
runtime: "claude-code"
role: "e2e-runner"
timeout: 450s

Approve Exact Dispatches

Nothing executes silently. When an agent requests filesystem modifications, package installations, or external calls, execution pauses for explicit cryptographic confirmation in your TUI.

# Approval policy trigger
prompt: "Execute sudo apt update?"
policy: "strict-human-signoff"
signature: "ed25519:workstation-key"

Observe, Audit, and Recover

Every transition is recorded in an append-only SQLite/WAL journal. If a laptop lid closes or WiFi drops, remote agents pause safely until the controller lease reclaims execution.

# Durable state recovery
storage: "wal-journal.sqlite"
recovery: "idempotent-replay"
lease_ttl: 30s ± 2s heartbeat
Execution Lifecycle

How a run moves through the mesh

From initial goal formulation to auditable commits, see the 5-stage pipeline that guarantees safety across physical and virtual machines.

STEP 01
Goal Formulation

Specify the task via CLI flags or composable YAML workflows with explicit input artifacts.

STEP 02
Task Graph DAG

AIBridge compiles dependencies, assigns optimal machine affinity, and configures bounded runtime roles.

STEP 03
Approval Gate

Policy checks evaluate intended commands against allowlists. Risky commands require a single keystroke in your TUI.

STEP 04
Native Agent Session

Dispatched across Tailscale to local loopback daemons. OpenCode, Claude Code, or Codex run in their native environments.

STEP 05
Auditable Result

Structured diffs and handoffs are recorded into SQLite/WAL. Raw token waste is replaced with scoped attributable memory.

Cryptographic Isolation

Engineered with an immutable safety floor

AI agents must never have unfettered access to infrastructure. AIBridge replaces trust with architectural guarantees.

01

Tailscale WireGuard Mesh

All traffic travels over point-to-point WireGuard tunnels authenticated via Tailscale identity. Zero public IP exposure, zero open ingress firewall ports, and zero relay dependencies.

02

Strict Loopback Confinement

OpenCode and partner runtimes bind exclusively to 127.0.0.1 on host machines. AIBridge acts as the sole authenticated gatekeeper, rejecting unauthorized cross-node calls.

03

Project Path Allowlists

Agents are restricted to explicit directory paths. Path traversal attempts (e.g. ../../etc/shadow) trigger immediate run suspension and operator alerts.

04

Scoped Attributable Memory

Instead of dumping multi-megabyte conversational transcripts between agents, AIBridge captures structured outputs, validated test results, and attributed code diffs.
